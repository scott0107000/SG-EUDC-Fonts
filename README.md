# 《SG输入法自造字》＋《GBK专用区》外字集开源免费解决方案

字言字型成功开发以《SG输入法自造字》及《GBK专用区》编码规格的字型，目的为在解决使用了该输入法的自造字或GBK编码之文件，在未安装该输入法的情况下能正确显示字形，而不会乱码。
## 字型
本字型解决方案包括１款风格：

- 字言SG自造字-黑体（`Fancy-SG-EUDC-Hei`）

字体内包含415个输入法自造字字符及105个GBK专用区字符，这些字符不另外映射至正字码位，仅适合在相关规格文件作为Fallback字型显示，不推荐使用字型内编码输入字符。

## 鸣谢
